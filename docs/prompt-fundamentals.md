# プロンプトの基礎

ChatGPTやClaudeなどのAIを使って、
思った通りの答えが返ってこない...

そんな経験はありませんか？

実は、AIへの質問の仕方を
少し工夫するだけで、
回答の質が大きく変わります。

その質問の仕方を「プロンプト」と呼びます。

今日は、このプロンプトの基礎について
お話をしていきたいと思います。


---


## プロンプトとは何か？

プロンプトとは、
AIに対して入力する文章のことです。

質問文や指示文、お願いごとなど、
あなたがAIに送るメッセージすべてが
プロンプトにあたります。

当たり前な話ですが、
人間同士の会話でも質問の仕方によって
返ってくる答えは変わりますよね？

AIとの対話も同じです。

**「何を」「どのように」伝えるか**で、
AIからの回答は大きく変わってきます。


---


## 良いプロンプトの4つの基本

では、良いプロンプトとは何か？

次の表をご覧ください。

| 基本 | ポイント |
|------|----------|
| 1. 明確さ | 何をしてほしいかをはっきり伝える |
| 2. 具体性 | 条件や詳細を具体的に書く |
| 3. 背景情報 | 状況や前提を共有する |
| 4. 出力形式 | どんな形で答えてほしいか伝える |

この表の意味を簡単に説明します。


### 1. 明確さ

まずは、何をしてほしいのかを
はっきり伝えることが大事です。

一見すると、
「文章を書いて」で十分な気がしますよね？

しかし、これでは曖昧すぎます。

```
新入社員向けに、
ビジネスメールの書き方を説明する文章を
300文字くらいで書いてください。
```

このように「誰向けに」「何について」
「どのくらいの長さで」を伝えると、
AIは的確な回答を返しやすくなります。


### 2. 具体性

「だいたいこんな感じで」よりも、
具体的な条件を伝えた方が
期待通りの結果になります。

例えば、プログラムを作ってほしい時。

```
Pythonで、CSVファイルを読み込んで、
売上金額の合計を計算するプログラムを作ってください。
ファイル名は「sales.csv」で、
「金額」という列の合計を出力したいです。
```

**「何を使って」「何をして」「どんな結果がほしいか」**

この3つを伝えることがポイントです。


### 3. 背景情報

AIはあなたの状況を知りません。

だからこそ、
必要な背景情報を一緒に伝えると、
より適切な回答をもらえます。

「このエラーを直して」だけでは
情報が足りません。

```
Webサイトを作っています。
ユーザーがログインしようとすると、
こんなエラーが出ます：
「TypeError: Cannot read property 'id' of undefined」
原因と解決方法を教えてください。
```

「何をしていて」「どんな状況で」起きたのかを
伝えることが大切です。


### 4. 出力形式

「どんな形で答えてほしいか」を
伝えておくと、
そのまま使える回答が返ってきます。

```
以下の項目を、表形式でまとめてください：
- 項目名
- 説明
- 優先度（高・中・低）
```

「箇条書きで」「表形式で」「3つにまとめて」など、
ほしい形を指定してみてください。

## 実際の事例で見てみましょう

「ChatGPT」や「Claude」は
知っていますでしょうか？

これらのAIに、
料理のレシピを聞く場面を想像してください。

**悪い例：**
```
夕飯のレシピを教えて
```

**良い例：**
```
一人暮らしの社会人向けに、
平日の夜でも15分で作れる夕食のレシピを
3つ考えてください。

条件：
- 材料はスーパーで手に入るもの
- 洗い物が少ないもの
- 栄養バランスも考慮

それぞれ、料理名・材料・手順を
分けて書いてください。
```

具体的にイメージできましたでしょうか？

後者は「誰向けに」「何を」「どんな条件で」
「どんな形式で」がすべて入っています。

**これが大事です。**


---


## よくある間違い

プロンプトでやりがちな失敗が
3つあります。

1. あいまいすぎる
2. 情報が足りない
3. 一度にたくさん頼みすぎる

特に3つ目は要注意です。

複雑なお願いは、
1つずつ順番に進めた方が
良い結果になります。

```
まず、以下のテーマでレポートの構成案を作ってください。
テーマ：「リモートワークのメリットとデメリット」

構成ができたら、次のステップに進みましょう。
```

このように分けて頼むのがコツです。


---


## まとめ

今日お伝えした、
良いプロンプトのポイントをまとめると、

1. **明確に** - 何をしてほしいかをはっきり伝える
2. **具体的に** - 条件や詳細を具体的に書く
3. **背景を伝える** - 状況や前提を共有する
4. **形式を指定する** - どんな形で答えてほしいか伝える
5. **1つずつ** - 複雑なことは分けて頼む

最初から完璧なプロンプトを
書く必要はありません。

「ちょっと違うな」と思ったら、
情報を足したり、言い方を変えたりしてみてください。

AIとの対話は、何度でもやり直せます。

あなたが今、AIを使う場面にも
応用して考えてみてください。

明日は、さらに便利なテクニックについて
説明しますね！
