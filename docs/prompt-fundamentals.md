# プロンプトの基礎

「ChatGPTやClaudeに質問しても、なんだか思った通りの答えが返ってこない...」

そんな経験はありませんか？実は、AIへの質問の仕方（これを「プロンプト」と呼びます）を少し工夫するだけで、驚くほど回答の質が変わります。

この記事では、AIを初めて使う方でもすぐに実践できる、プロンプトの基本をわかりやすくお伝えしていきます。

## プロンプトとは

プロンプトとは、AIに対して入力する文章のことです。質問文や指示文、お願いごとなど、あなたがAIに送るメッセージすべてがプロンプトにあたります。

人間同士の会話でも、質問の仕方によって返ってくる答えが変わりますよね。AIとの対話も同じです。「何を」「どのように」伝えるかで、AIからの回答は大きく変わってきます。

### なぜプロンプトが大切なのでしょうか

理由はシンプルです。

- AIは、あなたが書いた文章だけを頼りに回答を考えます
- あいまいな質問をすると、あいまいな答えが返ってきます
- 具体的に伝えれば、具体的で役立つ答えが返ってきます

つまり、プロンプトの書き方を少し意識するだけで、AIをもっと便利に活用できるようになるのです。

## 効果的なプロンプトの基本原則

ここでは、良いプロンプトを書くための4つの基本をご紹介します。難しく考える必要はありません。どれも日常のコミュニケーションで自然とやっていることばかりです。

### 1. 明確に伝える

まずは、何をしてほしいのかをはっきり伝えましょう。

**あいまいな例：**
```
文章を書いて
```

**明確な例：**
```
新入社員向けに、ビジネスメールの書き方を説明する文章を
300文字くらいで書いてください。
```

違いがわかりますか？後者は「誰向けに」「何について」「どのくらいの長さで」がはっきりしています。これだけで、AIは的確な回答を返しやすくなります。

### 2. 具体的に伝える

「だいたいこんな感じで」よりも、具体的な条件を伝えた方が期待通りの結果になります。

**あいまいな例：**
```
プログラムを作って
```

**具体的な例：**
```
Pythonで、CSVファイルを読み込んで、
売上金額の合計を計算するプログラムを作ってください。
ファイル名は「sales.csv」で、「金額」という列の合計を出力したいです。
```

プログラミングに詳しくなくても大丈夫です。ポイントは「何を使って」「何をして」「どんな結果がほしいか」を伝えることです。

### 3. 背景情報を伝える

AIはあなたの状況を知りません。だからこそ、必要な背景情報を一緒に伝えると、より適切な回答をもらえます。

**情報が足りない例：**
```
このエラーを直して
```

**背景情報がある例：**
```
Webサイトを作っています。
ユーザーがログインしようとすると、こんなエラーが出ます：
「TypeError: Cannot read property 'id' of undefined」
原因と解決方法を教えてください。
```

エラーメッセージだけでなく、「何をしていて」「どんな状況で」起きたのかを伝えると、AIも原因を特定しやすくなります。

### 4. 出力形式を指定する

「どんな形で答えてほしいか」を伝えておくと、そのまま使える回答が返ってきます。

```
以下の項目を、表形式でまとめてください：
- 項目名
- 説明
- 優先度（高・中・低）
```

「箇条書きで」「表形式で」「3つにまとめて」など、ほしい形を伝えてみてください。

## プロンプトの構成要素

ここまでの内容を整理すると、良いプロンプトには以下のような要素が含まれています。すべてを毎回入れる必要はありませんが、知っておくと便利です。

| 要素 | どういうこと？ | 例 |
|------|--------------|-----|
| **役割** | AIにどんな立場で答えてほしいか | 「料理の先生として教えて」 |
| **タスク** | 何をしてほしいか | 「レシピを考えて」 |
| **背景** | 状況や前提条件 | 「一人暮らしで調理器具が少ないです」 |
| **制約** | 守ってほしい条件 | 「15分以内で作れるもの」 |
| **例** | こんな感じで、という参考 | 「例：カレーライスのような定番料理」 |
| **形式** | どんな形で答えてほしいか | 「材料と手順を分けて書いて」 |

## 知っておくと便利なテクニック

ここからは、プロンプトをもっと上手に書くためのテクニックをいくつかご紹介します。名前は難しそうですが、やっていることはシンプルです。

### 1. そのまま聞く（ゼロショット）

一番シンプルな方法です。例を出さずに、そのまま質問します。

```
「人工知能」を英語に翻訳してください。
```

シンプルな質問なら、これで十分です。

### 2. 例を見せてから聞く（フューショット）

「こんな感じでお願い」と例を見せてから本題に入る方法です。AIが「ああ、こういう形式で答えればいいんだな」と理解しやすくなります。

```
以下の形式で、文章の感情を判定してください。

入力：「今日は最高の一日だった！」
出力：ポジティブ

入力：「電車が遅れて会議に遅刻した」
出力：ネガティブ

入力：「明日は雨かもしれない」
出力：
```

### 3. 順番に考えてもらう（思考の連鎖）

複雑な問題は、「順番に考えて」とお願いすると、AIも整理しながら答えてくれます。

```
以下の問題を、順番に考えて解いてください。

太郎くんは1000円持っています。
250円のパンを2つ買いました。
残りのお金で150円のジュースは何本買えますか？
```

計算問題だけでなく、複雑な相談ごとにも使えるテクニックです。

### 4. 役割をお願いする

「〇〇になったつもりで答えて」とお願いすると、その視点からの回答がもらえます。

```
あなたは小学校の先生です。
「なぜ空は青いの？」という質問に、
小学3年生にもわかるように答えてください。
```

専門家の視点がほしいとき、初心者向けの説明がほしいときなど、いろいろな場面で使えます。

### 5. 条件をつける

「こういう条件で」と指定すると、回答の範囲を絞り込めます。

```
以下の条件で説明してください：
- 難しい言葉を使わない
- 3文以内で
- 具体例を1つ入れる
```

## よくある間違いと改善方法

ここでは、やりがちな失敗と、その直し方をご紹介します。

### 間違い1：あいまいすぎる

**改善前：**
```
良い文章を書いて
```

**改善後：**
```
友人への誕生日メッセージを書いてください。
明るい雰囲気で、100文字くらいでお願いします。
```

「良い」の基準は人それぞれ。何がほしいのか具体的に伝えましょう。

### 間違い2：情報が足りない

**改善前：**
```
このエラーを直して
```

**改善後：**
```
Excelで関数を使おうとしたら「#VALUE!」というエラーが出ました。
セルA1に「=SUM(B1:B10)」と入力しています。
B列には数字と文字が混在しています。
原因と解決方法を教えてください。
```

AIはあなたの画面が見えません。状況をできるだけ詳しく伝えましょう。

### 間違い3：一度にたくさん頼みすぎる

**改善前：**
```
レポートを書いて、図も作って、
要約もして、英語にも翻訳して。
```

**改善後：**
```
まず、以下のテーマでレポートの構成案を作ってください。
テーマ：「リモートワークのメリットとデメリット」

構成ができたら、次のステップに進みましょう。
```

複雑なお願いは、1つずつ順番に進めた方が良い結果になります。

## 実践例

最後に、実際に使えるプロンプトの例をいくつかご紹介します。

### 例1：文章の添削をお願いする

```
以下のメール文を添削してください。

【添削してほしい点】
- 敬語の使い方が正しいか
- わかりにくい表現がないか
- 印象を良くする言い回し

【メール本文】
○○様

お世話になっております。
先日の件、ありがとうございました。
また何かありましたらよろしくお願いします。
```

### 例2：アイデアを出してもらう

```
一人暮らしの社会人向けに、
平日の夜でも15分で作れる夕食のアイデアを5つ考えてください。

条件：
- 材料はスーパーで手に入るもの
- 洗い物が少ないもの
- 栄養バランスも考慮

それぞれ、料理名と簡単な説明をつけてください。
```

### 例3：わからないことを質問する

```
プログラミング初心者です。

「API」という言葉をよく聞くのですが、
これが何なのかよくわかりません。

専門用語を使わずに、日常生活の例えを使って
説明してもらえますか？
```

## まとめ

この記事でお伝えした、良いプロンプトのポイントをおさらいしましょう。

1. **明確に** - 何をしてほしいかをはっきり伝える
2. **具体的に** - 条件や詳細を具体的に書く
3. **背景を伝える** - 状況や前提を共有する
4. **形式を指定する** - どんな形で答えてほしいか伝える
5. **1つずつ** - 複雑なことは分けて頼む

最初から完璧なプロンプトを書く必要はありません。「ちょっと違うな」と思ったら、情報を足したり、言い方を変えたりしてみてください。AIとの対話は、何度でもやり直せます。

いろいろ試しながら、自分なりのコツをつかんでいきましょう。
